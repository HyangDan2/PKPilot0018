## 1. 무엇이 추가되었나

Phase 3F는 “분석을 실행하는 것”에서 한 단계 더 나아가 **어떤 모형을 남길지, 무엇을 오차로 돌릴지, 그 결정을 어떻게 확인할지**를 다룬다.

| 기능 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 모형 항 선택 | 주효과·교호작용·2차항을 명시적으로 선택 | 설계가 추정할 수 없는 항을 추정한다고 주장하지 않음 |
| 오차 풀링 | 선택한 항을 제거하고 축소 모형을 자료에서 다시 적합 | 원본 SSE에 숫자를 더해 결과를 조립하지 않음 |
| 원본/축소 비교 | 두 적합의 10개 지표, 내포 관계, 부분 F를 보고 | R² 하나만으로 축소를 권고하지 않음 |
| 계층성 | strict·auto·unrestricted로 상위 항 규칙을 적용 | 교락을 고친다고 주장하지 않음 |
| 포화 설계 | DFE=0을 명시하고 Lenth·효과 그림으로 전환 | 없는 오차 자유도나 t/F 검정을 만들지 않음 |
| 모형 저장 | 수식·항·풀링 이력·계층성·오차 DF를 보존 | 저장 모형을 자동으로 최신 분석으로 바꾸지 않음 |

## 2. 시작하기

1. **Sample Library**에서 Phase 3F 샘플 네 개 중 하나를 불러온다.
2. **Stat → DOE → Analyze Factorial Design** 또는 **Stat → ANOVA → General Linear Model**를 연다.
3. 반응과 요인을 고르고 Options에서 모형 차수/교호작용을 설정한다.
4. Main 탭의 **Edit model**을 열어 항·풀링·계층성을 조정한다.
5. 실행한 뒤 출력 카드의 비교표·풀링 점검·효과 그림을 읽는다.
6. 남길 모형을 **Save model**으로 저장하고 Model Manager에서 수식과 이력을 확인한다.

| 샘플 | 행 수 | 목적 |

## 3. 모형 항 대화상자

### Selected terms

분석이 실제로 적합할 항만 선택한다. 제외 항은 결과에서 구분되며 계수로 fitting되지 않는다. DOE의 모형 차수는 출발점일 뿐이며, 대화상자에서 개별 항을 조정할 수 있다.

### Terms to pool

풀링 항은 **선택한 모형 항에서 제거**된다. 제거된 항의 SS와 df는 오차로 옮겨지는지를 풀링 점검에서 보고한다. 축소 모형은 별도의 설계행렬로 다시 적합된다.

### Hierarchy

| 모드 | 동작 | 사용 시점 |
| --- | --- | --- |
| Strict | 상위 항이 빠진 교호작용을 거부하고 이름을 표시 | 해석 가능한 계층 모형을 강제할 때 |
| Auto | 빠진 상위 항을 추가한 폐쇄를 저장 | 교호작용은 유지하면서 상위 항을 복구할 때 |
| Unrestricted | 선택을 그대로 두되 위반을 보고 | 분석가가 비계층 모형을 의도할 때 |

계층성과 교락은 다르다. 계층성은 **무엇을 모형에 넣을지**의 규칙이고, 교락은 **설계가 효과를 분리할 수 있는지**의 문제다. 자동 계층성으로 교락을 해결할 수 없다.

## 4. 오차 풀링과 부분 F

풀링 전에 다음을 확인한다.

- 항의 효과가 작고 p값이 그 항을 지지하지 않는가.
- 반복 또는 기존 오차 df가 실제로 있는가.
- 남은 모형이 공정의 질문을 표현하는가.
- 풀링 점검의 df·SS 가산성이 성립하는가.

실행 결과는 원본 적합(`full`)과 축소 적합(`fit`)을 함께 보존한다.

```text
F_partial = ((SSE_reduced − SSE_full) / df1) / MSE_reduced
df2       = DFE_reduced
```

부분 F는 다음 조건을 모두 만족할 때만 계산된다.

- 축소 모형이 원본에 내포됨
- 같은 행 집합을 사용함
- 자유도가 실제로 감소함
- 축소 모형에 오차 자유도와 양의 MSE가 있음

실패하면 수치를 억지로 만들지 않고 `not-nested`, `row-set-changed`, `no-reduction`, `no-error-df` 중 이유를 표시한다.

### 비교표 읽기

R²·R²adj·R²pred·S·MSE·DFE·SSE·PRESS를 함께 읽는다. R²pred를 계산할 수 없으면 0 대신 사유를 표시한다. 축소 모형이 “더 높은 R²”라는 이유만으로 채택되지는 않는다.

## 5. 반복 없는 설계와 Lenth

반복 없는 2ᵏ 완전 모형은 DFE=0이다. 이때 t검정·F검정·잔차 기반 S는 정의되지 않는다. Sigrún은 효과와 함께 Lenth 정보와 파레토 그림을 제공한다.

```text
s0        = 1.5 × median(|effect|)
inactive  = 0 < |effect| < 2.5 × s0
PSE       = 1.5 × median(|inactive effect|)
pseudo df = max(1, floor(m / 3))
ME        = t(0.975, pseudo df) × PSE
SME       = ME / 2
```

Lenth의 활성 표시는 **후속 실험을 고를 선별 규칙**이다. 유의성 입증이나 잔차 표준오차가 아니다. 활성 효과를 공정 변경의 근거로 쓰기 전에 반복 확인 실험을 설계해야 한다.

## 6. 불균형 GLM: Type I와 Type III

| 열 | 질문 | 성질 |
| --- | --- | --- |
| Type I / Seq SS | “이 항을 모형에 넣는 순서에서 추가할 때 설명하는 변동은?” | 항 순서에 따라 달라짐 |
| Type III / Adj SS | “다른 항을 모형에 두고 이 항을 마지막에 추가하면?” | Sum 코딩 기준의 부분 제곱합 |

불균형 설계에서는 두 값이 일반적으로 다르다. 관측 연구나 요인별 기여를 묻는 경우 Type III를, 모형 구축 순서의 기여를 묻는 경우 Type I을 읽는다. 두 열을 하나로 바꾸지 않는다.

## 7. 모형 저장과 호환성

Model Manager는 반응별 저장 모형의 수식·선택 항·풀링 이력·계층성·R²·R²adj·R²pred·S·오차 DF를 보여 준다. 저장 모형은 이후 등고선·표면·예측·최적화에서 사용할 수 있다.

- 기존 `.sigrun.json` 프로젝트는 새 선택 필드가 없어도 계속 열린다.
- 모형 저장 스키마는 v2로 확장됐지만 이전 v1 레코드는 읽는 경로를 유지한다.
- 풀링 원본/축소 결과와 모형 메타데이터는 배포 TypeScript 엔진에서 생성된다.
- 모든 데이터·문서·샘플은 번들에 포함되며 새 서버 API나 CDN이 필요하지 않다.
- 강제 종료는 세션을 끝내는 명령이다. 보관했던 실습을 다시 열었다면, 검증된 복원 뒤에 그 실습의 보관 사본도 함께 정리한다. 복원을 증명하지 못하면 사본을 남기고 복구 화면을 연다.

## 8. 알려진 한계

- 부분요인 설계의 별칭 항은 df 0으로 보고되며 계수를 추정하지 않는다.
- 풀링은 비직교 설계에서 SS 가산성이 실패할 수 있다. 실패한 점검을 숨기지 않는다.
- Lenth는 효과가 매우 적거나 척도가 퇴화하면 계산하지 않는다.
- 이 가이드의 수치는 문서화된 통계 정의와 독립 QA를 기준으로 하며, Minitab 실측 결과와의 동등성을 주장하지 않는다.
- Portable HTML의 브라우저 저장소가 차단되면 진행 저장이 실패할 수 있으며, 프로젝트 파일 내보내기를 대체 수단으로 사용한다.
