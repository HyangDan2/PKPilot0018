이 폴더의 파일
--------------
  Statelia-v1.0.0.html          응용 프로그램 전체가 한 파일에 들어 있습니다
  Statelia-v1.0.0-Portable.zip  위 파일과 짧은 안내문을 묶은 압축 파일
  Statelia-v1.0.0-Web.zip       정적 웹 빌드 (폴더를 서버로 열어 사용)
  SHA256SUMS.txt                    이 폴더의 다른 모든 파일의 sha256
  build-info.json                   버전·커밋·크기·해시
  LICENSES.txt                      서드파티 패키지와 라이선스
  VERSION.txt                       이 릴리스가 무엇인지 한 줄

포터블 빌드 실행
----------------
1. Statelia-v1.0.0.html 파일을 원하는 곳에 복사합니다.
2. 더블클릭하거나 Microsoft Edge·Google Chrome 창에 끌어다 놓습니다.

설치할 것이 없습니다. Node.js도, Python도, 서버도, 네트워크 연결도 필요하지
않습니다. 모든 통계·차트·내보내기는 브라우저 탭 안에서 계산됩니다. 브라우저
프로필보다 오래 보존해야 하는 작업은 파일 ▸ 프로젝트 저장을 사용하세요.

웹 빌드 실행
------------
1. Statelia-v1.0.0-Web.zip의 압축을 풉니다.
2. 그 폴더를 정적 웹 서버로 열고 주소를 엽니다.

웹 빌드의 index.html을 파일로 직접 열면 동작하지 않습니다(모듈 스크립트에는
출처가 필요합니다). file://로 쓰려면 포터블 파일을 사용하세요.

무결성 확인
-----------
  sha256sum -c SHA256SUMS.txt        (Linux)
  shasum -a 256 -c SHA256SUMS.txt    (macOS)

SHA256SUMS.txt 자신을 제외한 모든 파일의 해시가 들어 있습니다.

오프라인
--------
호스팅 페이지와 포터블 파일은 네트워크 요청을 하지 않습니다. 실제 브라우저에서
모든 요청을 기록해 감사했습니다. 외부로 나가는 것은 메뉴의 프로젝트 홈페이지
바로가기뿐이며, 사용자가 클릭할 때만 열립니다.
